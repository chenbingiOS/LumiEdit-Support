## 3. 视觉方向

明亮、简洁、自然、有摄影杂志的留白与节奏。优先展示大照片、真实编辑界面与轻微而可信的效果变化，让产品像一款成熟的摄影工具。

- 背景：柔和白 `#FAFAFA`；局部白色表面 `#FFFFFF`。
- 主文字：炭黑 `#222222`；次文字：`#666666`；细分隔线：`#E5E5E5`。
- 唯一界面强调色：暖橙 `#C74529`，用于主按钮、焦点和少量重点。照片可保留自然丰富色彩。
- 英文字体：优先自托管、许可清晰的 Outfit 或 Geist，保留系统无衬线回退；中文用苹方及系统中文字体回退。不要使用 Inter 或通用衬线字体。
- 主内容最大宽度约 1280px，桌面采用有节制的不对称网格，照片与文字各有清晰区域，不互相遮挡。
- 桌面主标题约 56–72px，移动端约 36–44px，使用 clamp 响应变化；正文 16–18px，适合阅读。
- 图片圆角约 16–24px，按钮触控高度至少 44px。避免巨大圆角胶囊包住所有内容。
- 不使用紫蓝霓虹、发光按钮、渐变大字、玻璃卡片堆叠、重复三列功能卡、装饰性数据面板、假浏览器编辑器、表情符号或自定义鼠标。
- 动效轻量，只服务于理解和操作反馈。禁止持续漂浮、打字机循环和自动轮播；支持 prefers-reduced-motion，正文加载后立即可读。
