# 正文变更与事实依据

## 处理原则

以迁移前 Support 仓库的六份正文作为基线，提取成双语结构化数据，保留原有权利、限制和披露；模板只提供排版参考，模板文字不作为新增事实的证据。版本能力描述以既有正文及项目技术核对为基线，未经过专业法律审核；iOS 分支中的实验和未来功能不据此宣传为已上架。

## 源码与项目依据

- `LumiPortrait/Sources/UI/Settings/AppDocumentViewController.swift`：六个公开 HTML 地址、WKWebView 临时数据存储、加载失败重试、HTTPS 与主动 mailto 导航。
- `LumiPortrait/Sources/Export/Files/PhotoShareFileStore.swift`：分享专用临时目录、文件保护、尽力删除及下次分享清理超过一天的文件；该行为不扩张为全部缓存的统一期限。
- `LumiPortrait/Resources/PrivacyInfo.xcprivacy`：未声明跟踪域名、跟踪为 false；仅为一个核对点，不能单凭清单断言所有网络活动为零。
- `LumiPortrait/Podfile`、`Resources/Licenses.txt`：存在本地第三方组件；没有把原生框架清单冒充完整 SDK 数据披露。
- `LumiPortrait/release/publisher.json`：Molly Lu、现有客服邮箱及网站 URL（不是法定通信地址）。
- `website/wrangler.jsonc`、`public/_headers`、现有 README：Cloudflare Static Assets、Pages 镜像、现有安全策略。
- `website/src/data/content.ts` 与原双语帮助页：只描述现有基础编辑能力；背景虚化保留“在提供该功能的版本中”的条件披露，不改为已上线承诺。

## 未采用的模板内容

- 手机模板把“更新”与“生效”合并，并承诺 15 个工作日响应；没有对应运营依据。
- “杜绝泄露风险”“纯净保障”“Zero cloud database”范围过宽，与网页日志及主动邮件事实不相符。
- “全部通过 Metal／Neural Engine”等实现描述与项目多种本地处理链不相符，也无助于用户理解权利。
- 用户照片和开源组件不能全部归为开发者专有知识产权；保留“相应权利人”表述。
- 英文模板的下载／使用即同意不能作为中文协议的默示新增义务。
- 不根据模板自行确定不满 14 岁的全球年龄规则、地区管辖条款或未实现的家长核验流程。

本次未访问 App Store Connect，也未重新查询商店公开版本。iOS 分支能力、历史公开版记录与实际已发布版本分别对待。
