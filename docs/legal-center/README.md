# 协议中心整合 · 2026-10-02

## 交付与入口

将用户提供的手机模板和桌面模板合成一套响应式页面，正文维护在 `website/src/legal/documents.json`，布局位于 `LegalDocument.tsx`，阅读增强与样式位于 `website/public/legal/`。

六个历史 URL 保持不变：`privacy`、`terms`、`support` × `en`、`zh-Hans`。不依赖浏览器识别、查询参数或原生代码改动；相同文档在 App 内网页和桌面浏览器使用同一份正文。主站根路径和 GitHub Pages 子路径共用相对链接。

- 桌面：轻量品牌导航、侧栏章节目录、限定宽度正文。
- 手机：单列阅读、可折叠目录、隐私／协议／帮助三个底部入口，不画手机框或仿原生返回栏。
- 两端：法律文件使用重要提示与条款编号，帮助页保留摘要；章节编号、完整展开的正文、字号调整、邮箱复制反馈、打印样式、键盘焦点、无脚本可读。
- 不增加独立“SDK 清单”或“儿童隐私”承诺页；已核实的第三方服务和未成年人内容放在隐私政策对应章节。没有引入模板中的在线搜索、账号图标、广告式承诺徽章、模型 API 或远程字体。

## 构建与维护

```sh
cd website
npm run legal:generate
npm run typecheck
npm run build
npm run build:pages
npm run verify
npm run sync:pages
npm run deploy:check
```

`dev` 和两个构建命令会先生成六份 HTML。`legal:check` 只读核对正文与产物，`verify` 同时检查完整正文、双语章节对应关系、目录目标、旧地址、无外部脚本和两种构建的一致性。不要手工修改生成的 HTML。源码变化后需重建再刷新预览。

根目录是 Pages 生成产物，本次仅本地同步；没有提交、推送或线上部署。iOS 源码、应用包和 App Store 未修改。默认关闭的营销功能开关保持原样。
