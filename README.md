# GlowMuse 协议与帮助网站

主站：[glowmuse.top](https://glowmuse.top/)，由 Cloudflare Workers 静态资源托管。

本仓库保留 GitHub Pages 历史地址兼容早期 App。各 HTML 页面通过规范地址标记和即时页面跳转指向自有域名的对应文档，同时保留完整正文作为后备内容。不设置 CNAME；自有域名由 Cloudflare 托管。

双语隐私政策、用户协议与帮助的文件名保持不变。后续内容由 App 项目的 `scripts/prepare-release-site.py` 生成；发布本仓库时，仅在 GitHub 副本增加跳转标签，不要将这些跳转标签复制回主站。
